# Glasses FoV Lab

## 1. 메타 SDK 사용
메타 공식 Meta XR SDK와 Meta VR CLI를 사용한 VR 글래스 시야각 체험 앱입니다.

## 2. 제작자
VR 유튜브 크리에이터 제콜이 만들었습니다.

made by zecole

## 3. 원클릭 설치 및 사용법
1. 이 저장소의 Releases에서 **GlassesFoVLab-0.3.4-Windows.zip**을 내려받아 압축을 모두 풉니다. APK만 받으면 PC 활성화 파일이 포함되지 않습니다.
2. Quest의 개발자 모드를 켜고 Windows PC에 데이터 USB 케이블로 연결합니다. 헤드셋에서 USB 디버깅을 허용합니다.
3. **Install-Quest.cmd**를 더블클릭하면 앱을 설치·업데이트하고 실행합니다. ADB가 없으면 최초 한 번 약관 동의 후 공식 도구를 다운로드합니다.
4. 다른 게임에서도 사용하려면 **Enable-Quest-Control.cmd**를 더블클릭합니다. 최초 실행에는 Meta 공식 CLI 다운로드를 위한 인터넷 연결이 필요합니다. 활성화가 끝나면 USB 케이블을 빼도 됩니다. 이전 버전에서 업데이트한 경우에도 새 ZIP의 이 파일을 한 번 실행해야 새 시야 비율이 적용됩니다.
5. Quest의 ‘알 수 없는 출처’에서 **Glasses FoV Lab**을 엽니다. **A 버튼 또는 왼쪽 스틱 클릭**으로 글래스 시야를 켭니다. ‘다른 게임에도 적용: 켜짐’을 확인하고 자동으로 화면이 잠깐 꺼졌다 켜질 때까지 기다립니다. 버튼은 한 번 누르고 놓으세요.
6. Meta 메뉴에서 원하는 게임을 실행합니다. 체험 앱이 종료돼도 시야 설정은 유지됩니다. 이미 실행 중이던 게임에 반영되지 않으면 게임을 종료하고 다시 실행하세요.
7. 기본 시야로 돌아오려면 체험 앱을 다시 열고 **A 버튼**으로 끈 뒤 자동 화면 갱신을 기다립니다. 헤드셋 재부팅으로도 초기화됩니다.
8. **Quest를 재부팅할 때마다 4번 USB 활성화를 다시 진행해야 합니다.** APK 재설치는 필요 없습니다.
9. **B**는 공간 전환, **X**는 정면 맞춤, **Y**는 화면 초기화입니다. 스틱 위아래로 왼쪽은 화면 거리, 오른쪽은 크기를 조절합니다. 오른쪽 스틱 클릭으로 한국어·영어를 전환합니다.
10. 다른 게임 적용은 Quest 3·3S·Pro 대상이며 실제 검증은 Quest 3에서 진행했습니다. Quest 2는 앱 내부 미리보기만 이용할 수 있습니다. 시야 변화는 헤드셋 안에서 확인하세요.
