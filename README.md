# Meta VR Glasses FoV Tester

## 1. 메타 SDK 사용
메타 공식 Meta XR SDK와 Meta VR CLI를 사용한 VR 글래스 시야각 체험 앱입니다.

## 2. 제작자
VR 유튜브 크리에이터 제콜이 만들었습니다.

made by zecole

## 3. 원클릭 설치 및 사용법
1. 이 저장소의 Releases에서 **GlassesFoVLab-0.4.5-Windows.zip**을 내려받아 압축을 모두 풉니다. APK만 받으면 PC 활성화 파일이 포함되지 않습니다.
2. Quest의 개발자 모드를 켜고 Windows PC에 데이터 USB 케이블로 연결한 뒤, 헤드셋에서 USB 디버깅을 허용합니다. 이 PC와 무선 디버깅으로 이미 페어링한 Quest라면 USB 없이 같은 Wi-Fi에서 자동으로 찾아 연결합니다.
3. **Install-Quest.cmd**를 더블클릭하면 앱을 설치·업데이트하고 실행합니다. ADB가 없으면 최초 한 번 약관 동의 후 공식 도구를 다운로드합니다.
4. 다른 게임에서도 사용하려면 **Enable-Quest-Control.cmd**를 더블클릭합니다. 최초 실행에는 Meta 공식 CLI 다운로드를 위한 인터넷 연결이 필요합니다. 활성화가 끝나면 USB 케이블을 빼도 됩니다. **이전 버전에서 업데이트한 경우에도 새 ZIP의 이 파일을 한 번 실행해야 합니다.**
5. Quest의 ‘알 수 없는 출처’에서 **Meta VR Glasses FoV Tester**(이전 이름 Glasses FoV Lab)를 엽니다. 화면 아래 조작 패널을 컨트롤러 레이저로 가리키고 트리거로 누릅니다. **글래스 시야** 스위치를 켜고, ‘다른 게임에도 적용: 켜짐’을 확인한 뒤 화면이 잠깐 꺼졌다 켜질 때까지 기다립니다.
6. Meta 메뉴에서 원하는 게임을 실행합니다. 체험 앱이 종료돼도 시야 설정은 유지됩니다. 이미 실행 중이던 게임에 반영되지 않으면 게임을 종료하고 다시 실행하세요.
7. 기본 시야로 돌아오려면 체험 앱을 다시 열고 **글래스 시야** 스위치를 끈 뒤 자동 화면 갱신을 기다립니다. 글래스 시야가 켜진 상태에서 앱을 열었다면, 끈 뒤 앱이 자동으로 다시 시작되며 기본 시야로 돌아옵니다. 헤드셋 재부팅으로도 초기화됩니다.
8. **Quest를 재부팅할 때마다 4번 활성화를 다시 진행해야 합니다.** APK 재설치는 필요 없습니다.
9. 조작 패널에서 공간 전환, 정면 맞춤, 초기화, 한국어·English 전환, 화면 크기·거리 조절을 할 수 있습니다. 스틱 위아래로도 왼쪽은 화면 거리, 오른쪽은 크기를 조절합니다. 잘못 눌러 시야가 바뀌지 않도록 컨트롤러 버튼에는 기능을 두지 않았습니다.
10. 다른 게임 적용은 Quest 3·3S·Pro 대상이며 실제 검증은 Quest 3에서 진행했습니다. Quest 2는 앱 내부 미리보기만 이용할 수 있습니다. 시야 변화는 헤드셋 안에서 확인하세요.
