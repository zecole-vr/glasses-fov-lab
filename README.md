# Meta VR Glasses FoV Tester

메타 공식 Meta XR SDK와 Meta VR CLI를 사용한 VR 글래스 시야각 체험 앱입니다.

VR 글래스 제품들의 시야각 차이를 Quest 안에서 직접 비교해 볼 수 있습니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 최신 버전 | **0.4.6** |
| 지원 기기 | Quest 3 · 3S · Pro (다른 게임 적용 포함, 실제 검증은 Quest 3) / Quest 2는 앱 내부 미리보기만 |
| 설치 도구 | [ZECOLE VR 런처](https://github.com/zecole-vr/zecole-launcher) (Windows 10/11 64비트, WebView2, .NET Framework 4.8) |
| 제작 | VR 유튜브 크리에이터 제콜 (made by zecole) · [YouTube](https://www.youtube.com/@zecole) |

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 앱 설치·업데이트와 다른 게임 적용을 모두 런처에서 합니다.

1. Quest의 개발자 모드를 켜고 Windows PC에 데이터 USB 케이블로 연결한 뒤, 헤드셋에서 USB 디버깅을 허용합니다.
2. 런처를 실행하고 왼쪽 목록에서 **Meta VR Glasses FoV Tester**를 고릅니다.
3. 설치 버튼을 누르면 앱을 설치·업데이트합니다.
4. 다른 게임에서도 사용하려면 **다른 게임에 적용 켜기**를 누릅니다. 활성화가 끝나면 USB 케이블을 빼도 됩니다.

### 알아 둘 점

- 런처에서 무선 연결을 켜 둔 Quest라면 USB 없이 같은 Wi-Fi에서 연결할 수 있습니다.
- ADB가 없으면 최초 한 번 약관 동의 후 공식 도구를 다운로드합니다.
- 다른 게임 적용을 처음 켤 때는 Meta 공식 CLI 다운로드를 위해 인터넷 연결이 필요합니다.
- 앱을 업데이트한 뒤에도 다른 게임 적용을 한 번 다시 켜야 합니다.
- **Quest를 재부팅할 때마다 런처에서 다른 게임 적용을 다시 켜야 합니다.** 앱 재설치는 필요 없고, 무선으로 연결돼 있으면 케이블 없이 다시 켤 수 있습니다.

## 사용법

1. Quest의 ‘알 수 없는 출처’에서 **Meta VR Glasses FoV Tester**(이전 이름 Glasses FoV Lab)를 엽니다.
2. 화면 아래 조작 패널을 컨트롤러 레이저로 가리키고 트리거로 누릅니다.
3. **글래스 시야** 스위치를 켜고, ‘다른 게임에도 적용: 켜짐’을 확인한 뒤 화면이 잠깐 꺼졌다 켜질 때까지 기다립니다.
4. Meta 메뉴에서 원하는 게임을 실행합니다.

- 체험 앱이 종료돼도 시야 설정은 유지됩니다.
- 이미 실행 중이던 게임에 반영되지 않으면 게임을 종료하고 다시 실행하세요.
- 시야 변화는 헤드셋 안에서 확인하세요.

### 기본 시야로 돌아가기

- 체험 앱을 다시 열고 **글래스 시야** 스위치를 끈 뒤 자동 화면 갱신을 기다립니다.
- 글래스 시야가 켜진 상태에서 앱을 열었다면, 끈 뒤 앱이 자동으로 다시 시작되며 기본 시야로 돌아옵니다.
- 헤드셋을 재부팅해도 초기화됩니다.

### 조작

- 조작 패널: 공간 전환, 정면 맞춤, 초기화, 한국어·English 전환, 화면 크기·거리 조절
- 스틱 위아래: 왼쪽은 화면 거리, 오른쪽은 크기 조절
- 잘못 눌러 시야가 바뀌지 않도록 컨트롤러 버튼에는 기능을 두지 않았습니다.
