# Glasses FoV Lab

## 1. 메타 SDK 사용
메타 공식 Meta XR SDK를 사용한 VR 글래스 시야각 체험 앱입니다.

## 2. 제작자
VR 유튜브 크리에이터 제콜이 만들었습니다.

made by zecole

## 3. 원클릭 설치법
1. Windows PC에서 [최신 배포](https://github.com/zecole-vr/glasses-fov-lab/releases/latest)의 **GlassesFoVLab-Windows.zip**을 다운로드하고 압축을 풉니다.
2. Quest의 개발자 모드를 켜고 데이터 전송이 가능한 USB 케이블로 PC에 연결합니다. 헤드셋 안에서 **USB 디버깅 허용**을 선택합니다.
3. 압축을 푼 폴더에서 **Install-Quest.cmd**를 더블클릭합니다. ADB가 없는 PC에서는 최초 한 번 Android SDK 약관 확인 후 `Y`를 입력하면 공식 도구를 다운로드합니다.
4. 앱이 자동으로 설치·업데이트되고 실행됩니다. 여러 Quest가 연결되어 있으면 설치할 기기 번호를 선택합니다.
